# Prodigy — концепт сайта

Неофициальный демонстрационный сайт центра обучения иностранным языкам Prodigy в Комсомольске-на-Амуре.

## Запуск

```bash
npm install
npm run dev
```

## Источники

Контакты, направления и фотографии взяты с публичной страницы организации в 2ГИС. Цены, расписание и состав преподавателей намеренно не указаны без подтверждения владельца.

Сайт подготовлен как дизайн-концепт и может быть передан владельцу организации для согласования и дальнейшей доработки.
